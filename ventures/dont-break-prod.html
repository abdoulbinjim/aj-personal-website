01 THE IDEA
WHY DON'T BREAK PROD EXISTS

Writing code
is one thing. Trusting it is another.

AI can generate code at extraordinary speed. But someone still has to decide whether that code is safe to deploy.

A proposed change can look perfectly reasonable while quietly violating a requirement, introducing a regression, or changing behaviour that other systems depend on.

Don't Break Prod turns that challenge into an interactive learning experience. Instead of simply writing code, you practise the judgment required to review it.

The goal is to become better at spotting risky changes, challenging assumptions, and making informed production decisions.

THE CENTRAL QUESTION Does this change actually honour the contract?
